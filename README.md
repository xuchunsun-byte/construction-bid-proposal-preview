# Construction Bid Proposal Deck

A 16-page editable PowerPoint and Google Slides template for small English-language contractors, subcontractors, and engineering firms who need to present a job bid or tender.

This repository hosts the public preview: eight of the sixteen slides, plus a free 8-page sample you can download and edit. The full pack is a $19 one-time purchase from a button on the preview page.

Preview: https://xuchunsun-byte.github.io/construction-bid-proposal-preview/

This is a presentation template, not a bid-writing service.
